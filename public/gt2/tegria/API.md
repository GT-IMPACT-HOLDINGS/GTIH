# Moved — GTIH API overview

The shared HTTP/SDK contract Lexiom offers is **GTIH**, not Tegria.

See **[../gtih/API.md](../gtih/API.md)** (includes a review diagram).

**Tegria’s role (parallel):** a **wrapper SDK** over GTIH for Tegria UI developers, developed **alongside** GTIH/Lexiom/TRH—not after them. The wrapper may integrate **domain-related and/or tenant-bounded** data from a **remote Tegria server**, for the user/player’s benefit, raising the **economic value** of the unified SDK for that vertical. TRH and this folder’s instrument SPA call **GTIH directly**.
